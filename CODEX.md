# CODEX.md

Ce fichier rassemble les règles du projet et les consignes imposées pour ce dépôt.

## Objectif du projet

- Créer un petit site web avec Vite.
- La page d’accueil doit afficher un gros bouton en forme de coeur avec le texte `Mon amour !`.
- Au clic, une nouvelle page doit apparaître avec le texte `Je t'aime beaucoup`.
- Cette nouvelle page doit déclencher une explosion de pétales de roses.
- L’explosion doit être visible, généreuse et composée de pétales assez gros.

## Règles fonctionnelles

- La page d’accueil et la nouvelle page doivent être distinctes dans l’interface.
- Le clic sur le coeur doit provoquer la transition vers la nouvelle page.
- Les pétales doivent être générés en JavaScript.
- Les pétales doivent disparaître automatiquement après leur animation.
- Le comportement doit rester simple et lisible.

## Règles de style et de contenu

- Le projet doit être rédigé en français.
- Le `README.md` doit être clair, corrigé et utile.
- Le `CHANGELOG.md` doit être en français.
- Le `CHANGELOG.md` doit contenir une date pour chaque entrée ou bloc de changements.
- Les textes du projet doivent respecter les accents et l’orthographe française.

## Règles de travail

- Ne pas demander de validation intermédiaire sauf blocage technique.
- Exécuter directement les tâches demandées quand elles sont faisables.
- Si un fichier de consigne est mis à jour, le relire avant d’agir.
- Préserver les modifications déjà présentes dans le dépôt sauf demande explicite contraire.

## Contraintes techniques

- Utiliser Vite comme base du projet.
- Garder une implémentation en JavaScript vanille.
- Préserver une structure de code simple et facile à modifier.
- Vérifier le build quand une modification importante est faite.

## Historique de consignes importantes

- Créer le site avec Vite.
- Afficher un coeur cliquable avec `Mon amour !`.
- Faire apparaître une nouvelle page avec `Je t'aime beaucoup`.
- Ajouter une explosion de pétales de roses.
- Augmenter la taille et l’intensité de l’explosion.
- Corriger et améliorer le `README.md`.
- Créer un `CHANGELOG.md` en français avec des dates.
