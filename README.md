# Web Love 💘

Un petit site Vite romantique :

- une home page avec un gros bouton cœur **« Mon amour ! »**
- une page finale avec **« Je t'aime beaucoup »**
- une explosion animée de pétales de roses

## Démarrage

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Puis ouvre :

- `http://localhost:5173/`
- ou l’adresse réseau affichée par Vite

## Build

```bash
npm run build
```

## Aperçu

Clique sur le cœur pour révéler la scène finale. 💖
