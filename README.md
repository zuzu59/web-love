# Tutu

Un projet Vite minimaliste.

## Démarrer le projet

### Installation des dépendances
```bash
npm install
```

### Mode développement
Pour lancer le serveur de développement :
```bash
npm run dev
```

Ou, pour le rendre accessible sur le réseau (avec une adresse IPv4) :
```bash
npm run dev -- --host
```

### Build pour la production
```bash
npm run build
```

### Aperçu du build
```bash
npm run preview
```

## Structure du projet

- `src/` - Code source
- `public/` - Fichiers statiques
- `index.html` - Point d'entrée HTML
- `vite.config.js` (optionnel) - Configuration Vite
